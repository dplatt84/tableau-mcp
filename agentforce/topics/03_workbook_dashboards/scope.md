### What You CAN Do

- Retrieve detailed workbook information including all views
- Get high-resolution images of views/dashboards
- Export view data as CSV
- Browse views within workbooks
- Access workbook metadata (views, tags, descriptions, usage statistics)
- View multiple sheets from a workbook
- Present visual dashboards to users

### What You CANNOT Do

- Modify workbook content or structure
- Edit views or dashboards
- Create new workbooks or views
- Change workbook permissions
- Refresh extracts
- Modify workbook settings or configurations
- Access unpublished or private workbooks without permissions

### Prerequisite Conditions

- User must have read access to workbooks/views
- Content must be published on the Tableau site
- For view images: views must be accessible
- For view data: user needs download permissions
